# Read first

**Before a given kind of task, read these — and only these.** The constitution says where things live; this file says what a task needs, so an agent reads three files instead of thirty, or none.

Loads on demand, at the start of a task. It is not in the always-loaded set, so it can grow with the work without costing every session.

**When to add a row:** an agent got something wrong because it did not read a file it should have. That is the evidence. Add the row at wrap-up or retro, naming the failure in the last column. A row nobody can justify is noise; delete it at retro.

| Before you… | Read | Because |
|---|---|---|
| Generate anything | `foundations/`, `learning/corpus/rejected/` | Invented detail and repeated rejections are the two commonest failures |
| Judge or review output | `rubrics/`, `contracts/review.md` | A review with no written standard grades against taste |
| Suggest a change to how the work runs | `decisions/log.md` — especially *Do not propose again* | Turned-down ideas come back when nobody checks |
| Edit the harness itself | `GOVERNANCE.md`, `loading-order.md` | Who may decide, and what it costs every session |
| Rely on something remembered | `memory/`, then the file or setting it names | Memory describes the past; check it still holds |
| Fix something someone found wrong | `procedures/learn-from-finding.md`, `learning/findings.md` | A fixed instance teaches nothing, and the same finding comes back |
| End a working session | `procedures/session-wrapup.md` | Corrections not written down get made again |
| Run a retro | `procedures/harness-retro.md`, `learning/retros.md` | What changed since last time, and whether the always-loaded set grew |
| Prepare feedback for the source harness | `procedures/upstream-feedback.md`, the accepted retro finding | Product context must not travel with a reusable harness lesson |
