# Contract: Brief

What must exist before work starts.

## Required

- **Problem / job** — what someone needs, traced to a foundation file
- **Surface** — which lane in `config/surfaces.tsv`, which sets blast radius and approval
- **Scope** — what is in, and what is explicitly out
- **Acceptance criteria** — testable statements of done
- **Constraints** — deadline, dependencies, existing work to reuse

## Optional

- References, prior art, sketches
- Open questions — resolved or explicitly deferred before work begins

**A brief missing any required field has not started the workflow.** Do not infer a missing field; ask.
