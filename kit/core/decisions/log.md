# Decision log

One line per decision that someone taking over in three months would need to know. Newest first. Check here before proposing a change to how this work runs.

Record the decision **before** building on it, not after: a decision written up afterwards describes what was built, not why. When a line needs more than a sentence of context, write `decisions/NNNN-<title>.md` from `decisions/0000-template.md` and link it.

**Never delete a line.** When a decision is replaced, strike it through (`~~like this~~`) and add the new line above it, naming the one it replaces. The struck line is how the next person learns the question was already asked.

Procedure: `procedures/record-decision.md`.

## Open questions

Questions about what is intended that nobody here can answer yet — often raised
by whoever used the output: *"is it on purpose that…?"*. An agent does not pick
an answer; it logs the question. A question closes only into a decision line
above (its date), or with why none is needed. An answer left in the thread where
it was asked is asked again.
