# Code of conduct

Agent Harness follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. Harassment, personal attacks and sharing others' private information aren't welcome.

To report a problem, email the maintainer, [@stevensmith-design](https://github.com/stevensmith-design), at [genten.steven+conduct@gmail.com](mailto:genten.steven+conduct@gmail.com). Reports are handled privately.
