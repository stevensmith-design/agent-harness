# Decisions

Architecture Decision Records in [MADR](https://adr.github.io/madr/) format.
`NNNN-short-title-with-dashes.md`, numbered in order, never renumbered.

An **accepted** ADR is binding on agents and humans alike. It sits above project
decisions in the authority chain (`AGENTS.md`). To change one, write a new ADR
that supersedes it — do not edit history.

Every ADR carries a **Confirmation** section saying how the decision is checked.
That is what separates a record from a wish.

Write one with the `adr` skill.
