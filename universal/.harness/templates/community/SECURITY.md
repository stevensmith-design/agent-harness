# Security policy

## Reporting a vulnerability

Please report privately, not in a public issue: {{SECURITY_CONTACT}}

Include what you found, how to reproduce it, and what it affects. Use fake values in examples, never real secrets or personal data.

## What to expect

{{PROJECT_NAME}} is maintained on a best-effort basis. Reports are acknowledged as soon as the maintainers can, and fixed in the latest version.

## Supported versions

Only the latest release, or the latest commit on the default branch if there are no releases.
