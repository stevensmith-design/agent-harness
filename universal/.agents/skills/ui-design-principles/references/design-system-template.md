# Layer 3 · Tokens & component rules
<!-- The exact values. Mirrored 1:1 in tokens.json — when a value changes, change it in both. -->

## Spacing scale

All spacing is on an 8pt grid. Fine-grained internal spacing uses 4pt multiples.

```css
--space-1:   4px;   /* icon-to-label gap, tight internal */
--space-2:   8px;   /* compact padding, adjacent element gap */
--space-3:  12px;   /* small component internal padding */
--space-4:  16px;   /* standard element spacing, default padding */
--space-5:  24px;   /* component separation */
--space-6:  32px;   /* section internal spacing */
--space-7:  48px;   /* between sections */
--space-8:  64px;   /* major section breaks, hero padding */
--space-9:  96px;   /* page-level vertical rhythm */
```

**Spacing usage notes:**
<!-- Project-specific spacing decisions, e.g.:
     "Cards use --space-4 (16px) internal padding on desktop, --space-3 (12px) on mobile."
     "Section gaps use --space-7 (48px); subsection gaps use --space-5 (24px)." -->

## Border radius scale

```css
--radius-sm:    px;   /* inputs, chips, tooltips — default 4–8px */
--radius-md:    px;   /* cards, panels, modals — default 12px */
--radius-lg:    px;   /* large containers — default 16px (max for cards) */
--radius-pill: 999px; /* tags, badge pills */
```

**Rule:** Cards and containers use `--radius-md` or `--radius-lg` maximum. Any value above 16px
requires a logged override (a soft/playful mobile direction may commit 20–24px as the system value).
**Concentric radius rule:** nested rounded elements derive their radius from the container:
`inner-radius = outer-radius − gap`.

## Color tokens

```css
/* ── Semantic roles ──────────────────────────────── */
--color-primary:      ;   /* Main CTA, key buttons */
--color-primary-hover:;   /* Hover state of primary */
--color-secondary:    ;   /* Supporting actions */
--color-destructive:  ;   /* Delete, irreversible actions */
--color-success:      ;   /* Confirmation, completion */
--color-warning:      ;   /* Caution, pending */
--color-error:        ;   /* Failure, validation error */
--color-info:         ;   /* Neutral informational */

/* ── Surfaces ────────────────────────────────────── */
--color-bg:           ;   /* Page background */
--color-surface:      ;   /* Card/panel background */
--color-surface-alt:  ;   /* Secondary surface (e.g. sidebar) */
--color-border:       ;   /* Dividers, input borders */

/* ── Text ────────────────────────────────────────── */
--color-text:         ;   /* Primary body text */
--color-text-muted:   ;   /* Secondary text, placeholders */
--color-text-inverse: ;   /* Text on dark/colored surfaces */
```

<!-- Product-specific semantic roles (if any): e.g. --color-category-a, --color-status-live -->

**Rule:** Every color value in the codebase must map to one of these tokens. No ad-hoc hex in components.

**Neutral ramp rule:** derive `--color-bg`, `--color-border`, `--color-text-muted`, and
`--color-text` from **one brand-tinted neutral ramp** (~9 steps, brand hue at 2–8% chroma).
Canvas ≈ L 96–98%; cards pure `#FFFFFF`; background↔card value step 1.05–1.12:1. Never dead-gray
neutrals under a colourful brand; never high-chroma neutrals on the canvas. (The validator checks
this — see Layer 4.)

## Typography

```css
/* ── Font families ───────────────────────────────── */
--font-display:  ;   /* Headings, hero text — must be a distinctive choice */
--font-body:     ;   /* Body text, UI copy */
--font-mono:     ;   /* Code, data, timestamps */

/* ── Size scale (1.25× minimum ratio between heading levels) ── */
--text-xs:    12px / 0.75rem;
--text-sm:    14px / 0.875rem;
--text-base:  16px / 1rem;
--text-lg:    18px / 1.125rem;
--text-xl:    20px / 1.25rem;
--text-2xl:   24px / 1.5rem;
--text-3xl:   30px / 1.875rem;
--text-4xl:   36px / 2.25rem;
--text-5xl:   48px / 3rem;

/* ── Line height ─────────────────────────────────── */
--leading-tight:   1.25;   /* display headings */
--leading-snug:    1.375;  /* subheadings */
--leading-normal:  1.5;    /* UI copy */
--leading-relaxed: 1.625;  /* body/prose (target: 1.5–1.7) */

/* ── Letter spacing ──────────────────────────────── */
--tracking-tighter: -0.04em;  /* display headings (floor — don't go tighter) */
--tracking-tight:   -0.02em;
--tracking-normal:   0em;
--tracking-wide:     0.05em;  /* short uppercase labels only (4–6 words max) */
```

**Heading assignments:**

| Level | Size token | Line height | Tracking | Font |
|-------|-----------|-------------|----------|------|
| h1 | `--text-` | `--leading-` | `--tracking-` | `--font-display` |
| h2 | `--text-` | `--leading-` | `--tracking-` | `--font-display` |
| h3 | `--text-` | `--leading-` | `--tracking-` | `--font-display` |
| body | `--text-base` | `--leading-relaxed` | `--tracking-normal` | `--font-body` |
| label | `--text-sm` | `--leading-normal` | `--tracking-normal` | `--font-body` |
| caption | `--text-xs` | `--leading-normal` | `--tracking-normal` | `--font-body` |

**Rule:** Size ratio between adjacent heading levels must be ≥ 1.25×. Body text minimum: 14px
(dense UI), 16px (reading-focused). (The validator checks heading ratios — see Layer 4.)

## Elevation (surface & shadow)

Elevation is tied to layer **role** (Layer 2), not eye-tuned per element. Shadows are neutral
(near-black), never brand-tinted; a static data card carries **no** shadow.

```css
--elev-0:  none;                                                       /* static / data cards — separate via hairline + value step */
--elev-1:  0 1px 2px  rgba(17,24,22,0.06);                             /* tappable cards, tab bar */
--elev-2:  0 4px 12px rgba(17,24,22,0.08);                             /* menus, popovers, key raised surfaces */
--elev-3:  0 12px 32px rgba(17,24,22,0.12);                            /* sheets, modals */
```

**Rules:** The ramp is generative — as elevation rises, blur/offset grow while opacity *falls*.
Positive y-offset only (no `0 0` glows). Structural card shadows stay ≤ 16px blur; only the
sheet/modal layer goes wider. A card separates by border OR value-step+shadow — never a border
plus a wide decorative shadow (ghost-card). Dark mode roughly doubles the opacities.

## Component rules

### Cards — three role-based primitives

Pick the primitive by what the card **is**, not by how it should look. Default to `.card-static`;
a card earns a shadow only when it is genuinely tappable or floating (elevation-by-role, Layer 2).

```css
/* Static / data card — roster, settings group, read-only content.
   Flat: value step + hairline, NO shadow (a shadow makes a non-tappable card look tappable). */
.card-static {
  border-radius: var(--radius-md);
  padding:       var(--space-4);
  background:    var(--color-surface);  /* opaque #FFFFFF on a slightly-off-white canvas */
  border:        1px solid var(--color-border);   /* delicate hairline */
  box-shadow:    var(--elev-0);         /* none */
}

/* Interactive / floating card — the card itself is tappable, or it's a popover/menu. */
.card-interactive {
  border-radius: var(--radius-md);
  padding:       var(--space-4);
  background:    var(--color-surface);
  box-shadow:    var(--elev-1);         /* no hairline — shadow is the separation */
}

/* Overlay surface — sheets and modals. */
.card-overlay {
  border-radius: var(--radius-lg);
  padding:       var(--space-5);
  background:    var(--color-surface);
  box-shadow:    var(--elev-3);
}
```

### Buttons

```css
/* Primary */
.btn-primary {
  height:          44px;             /* 44px web / 44pt iOS / 48dp Android */
  padding-inline:  var(--space-4);
  border-radius:   var(--radius-);   /* fill in */
  background:      var(--color-primary);
  font:            500 var(--text-sm) / 1 var(--font-body);
}
```

States required: default, hover, active, disabled (`aria-disabled`), loading (spinner + preserved
label). One primary button per screen maximum.

### Form inputs

```css
.input {
  height:        40px;               /* 40px web / 44pt iOS / 48dp Android */
  padding:       var(--space-2) var(--space-3);
  border-radius: var(--radius-sm);
  border:        1px solid var(--color-border);
  font:          var(--text-base) / 1 var(--font-body);
}
```

Rule: Every input paired with a persistent visible `<label>`. Placeholder is for format hints only.

### Icons

- **Icon family:** <!-- SF Symbols / Material Symbols / Lucide / Phosphor — pick ONE, one stroke weight -->
- System chrome: SVG icons only (no emoji in interactive elements). Filled vs outline only as a state system.
- Icon sizes: 16px / 20px / 24px (snap to scale)
- Touch target minimum: 44px — pad with transparent area if icon is smaller

### Modals / sheets

- Full-screen modal: multi-step flows, onboarding, media
- Bottom sheet / half-modal: settings, quick actions, confirmations
- Toast: success and info only — never for errors requiring action

## Motion

```css
--ease-out:      cubic-bezier(0.25, 1, 0.5, 1);    /* ease-out-quart — default entrance for all UI */
--ease-exit:     cubic-bezier(0.4, 0, 1, 1);       /* ease-in — exits run ~0.8× faster */
--duration-fast:   150ms;   /* hover, small state changes */
--duration-normal: 250ms;   /* panel open, dropdown */
--duration-slow:   350ms;   /* modal, page transition */
```

Rules: No bounce or elastic easing. Animate `transform` and `opacity` only — not
width/height/padding/margin. `@media (prefers-reduced-motion: reduce)` → instant or crossfade.

## Tap targets

| Platform | Minimum | Adjacent spacing |
|----------|---------|-----------------|
| Web      | 24×24 CSS px WCAG AA (including spacing exception); ~44px preferred for touch-heavy controls | Contextual / WCAG spacing exception |
| iOS      | 44×44pt | ≥ 8pt |
| Android  | 48×48dp | ≥ 8dp |

Add transparent padding to small elements to meet minimums.

## Run the validator

The token-graph validator computes the relationships and gates them. Run it after any token change:

```bash
python3 .claude/skills/scripts/validate-tokens.py <project-dir>
```

Resolve every `FAIL` before shipping. A `PASS` means the relationships cohere — it is not visual
sign-off (it cannot see layout, rhythm, or taste).
